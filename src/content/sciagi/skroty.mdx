<Note title="Układ klawiszy">
Skróty dla Windows i Linuksa (domyślny układ IntelliJ i Android Studio). Na macOS zamiast `Ctrl` zwykle jest `Cmd`. Oba programy są od JetBrains, więc skróty są prawie identyczne.
</Note>

## Pięć skrótów, które musisz mieć w palcach

| Skrót | Co robi | Kiedy na egzaminie |
|---|---|---|
| `Alt+Enter` | szybka naprawa: import klasy, poprawka błędu, wyciągnięcie tekstu do `strings.xml` | przy każdym czerwonym podkreśleniu |
| `Ctrl+Space` | podpowiadanie kodu | ciągle |
| `Ctrl+Alt+L` | formatowanie (wcięcia, spacje) | **przed oddaniem**: kryteria R.1.1 i R.1.2 |
| `Shift+F10` | uruchom | |
| `Alt+Insert` | generuj: konstruktor, gettery, settery, `toString` | przy każdej klasie |

## Szablony (wpisz i naciśnij Tab)

| Wpisz | Dostaniesz |
|---|---|
| `psvm` albo `main` | `public static void main(String[] args) { }` |
| `sout` | `System.out.println();` |
| `souf` | `System.out.printf("");` |
| `soutv` | `System.out.println("zmienna = " + zmienna);` (ostatnia zmienna) |
| `fori` | `for (int i = 0; i < ; i++) { }` |
| `itar` | pętla po tablicy z indeksem |
| `iter` | pętla for-each |
| `ifn` / `inn` | `if (x == null)` / `if (x != null)` |
| `/**` + Enter | szkielet komentarza dokumentacyjnego nad metodą |

## Edycja

| Skrót | Co robi |
|---|---|
| `Ctrl+D` | duplikuj linię |
| `Ctrl+Y` | usuń linię |
| `Ctrl+/` | komentarz `//` dla linii lub zaznaczenia |
| `Ctrl+Shift+/` | komentarz blokowy `/* */` |
| `Alt+Shift+↑/↓` | przesuń linię w górę/dół |
| `Ctrl+W` | rozszerzaj zaznaczenie (słowo → wyrażenie → blok) |
| `Shift+F6` | zmień nazwę wszędzie (też nazwę pliku klasy) |
| `Ctrl+Alt+V` | wyciągnij wyrażenie do zmiennej |
| `Ctrl+Alt+M` | wyciągnij zaznaczony kod do metody |
| `Ctrl+O` | nadpisz metodę rodzica (np. `toString`, `onCreate`) |
| `Ctrl+Alt+O` | usuń nieużywane importy |
| `Ctrl+Z` / `Ctrl+Shift+Z` | cofnij / ponów |

| Skrót | Co robi |

| `Ctrl+Shift+F` | szukaj we wszystkich plikach |

## Tylko Android Studio

| Skrót / miejsce | Co robi |
|---|---|
| `Ctrl+F10` | Apply Changes and Restart Activity: wgraj zmiany bez pełnej reinstalacji |
| `Ctrl+Alt+F10` | Apply Code Changes: tylko zmiany w kodzie Javy |
| `Alt+6` | Logcat (komunikaty i błędy aplikacji: tu szukasz przyczyny „aplikacja przestała działać”) |
| Code / Split / Design | przyciski w prawym górnym rogu edytora XML: tekst, podgląd, oba naraz |
| `Alt+Enter` na tekście w XML | Extract string resource |
| Device Manager | tworzenie emulatora (np. Pixel 5) |

## Zrzuty ekranu w Windows (do dokumentacji)

Arkusz wymaga **całego ekranu z paskiem zadań** i widocznym środowiskiem.

| Skrót | Co robi |
|---|---|
| `Win+PrtScn` | zrzut całego ekranu od razu zapisany w Obrazy → Zrzuty ekranu |
| `PrtScn` | cały ekran do schowka (wklej w Paint i zapisz) |
| `Win+Shift+S` | wycinek ekranu: wybierz tryb „pełny ekran”, bo prostokąt nie spełni wymogu |

Zapisuj od razu pod nazwami z arkusza: `konsola1`, `konsola2`, `mobile1`…
