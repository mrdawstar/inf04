## Szkielet programu

```java title="Main.java" stdin="5"
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Podaj liczbę: ");
        int n = sc.nextInt();
        System.out.println("Wpisano " + n);
    }
}
```

## Typy i zmienne

| Typ | Przykład | Uwagi |
|---|---|---|
| `int` | `int ile = 0;` | ±2,1 mld |
| `long` | `long duza = 5_000_000_000L;` | L na końcu |
| `double` | `double cena = 4.40;` | ułamki |
| `boolean` | `boolean ok = true;` | true / false |
| `char` | `char c = 'a';` | apostrofy |
| `String` | `String s = "tekst";` | cudzysłowy, `equals` |
| stała | `final int MAX = 6;` | WIELKIE_LITERY |
| rzutowanie | `(int) 7.9` → 7, `(double) a / b` | obcina, nie zaokrągla |

**int / int obcina:** `7 / 2` = 3, `7 / 2.0` = 3.5, `7 % 2` = 1.

## String i char

| Kod | Wynik dla `s = "Kajak"` |
|---|---|
| `s.length()` | 5 (z nawiasami) |

## Klasa

```java check="types"
class Kostka {
    private int wartosc;                       // pole (prywatne)
    private static int liczbaKostek = 0;       // wspólne dla wszystkich

    public Kostka() {                          // konstruktor bezparametrowy
        this(1);
    }

    public Kostka(int wartosc) {               // z parametrem
        this.wartosc = wartosc;
        liczbaKostek++;
    }

    public Kostka(Kostka inna) {               // kopiujący
        this(inna.wartosc);
    }

    public int getWartosc() { return wartosc; }
    public static int getLiczbaKostek() { return liczbaKostek; }

    @Override
    public String toString() { return "Kostka: " + wartosc; }
}

class ZlotaKostka extends Kostka {             // dziedziczenie
    public ZlotaKostka() { super(6); }         // super: konstruktor rodzica
}
```

## Losowanie i Math

| Kod | Co daje |
|---|---|
| `new Random().nextInt(6) + 1` | kostka 1–6 |
| `r.nextInt(max - min + 1) + min` | zakres [min, max] |
| `t[r.nextInt(t.length)]` | losowy element |
| `Math.max(a, b)`, `Math.abs(x)` | większa, moduł |
| `Math.pow(a, b)`, `Math.sqrt(x)` | potęga, pierwiastek (double) |
| `Math.round(x * 100) / 100.0` | 2 miejsca po przecinku |
